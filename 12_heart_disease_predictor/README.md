# Heart Disease Risk Prediction

A cardiovascular diagnostic classification system that evaluates patient medical attributes (chest pain, resting blood pressure, cholesterol, ECG) to predict heart disease presence.

---

## 📌 Project Overview
* **Notebook:** [Heart_Disease_Prediction.ipynb](Heart_Disease_Prediction.ipynb)
* **Technologies:** Python, Pandas, Scikit-Learn, Logistic Regression, Seaborn
* **Author:** Muhammad Roman Khan

---

## 🚀 Workflow & Key Steps
1. Cardiovascular clinical data loading
2. Statistical analysis and null value audit
3. Target distribution visualization (Healthy: 0, Heart Disease: 1)
4. Correlation heatmap of clinical variables
5. Stratified train-test split
6. Logistic Regression model fitting
7. Training and test accuracy evaluation
8. Clinical predictive system evaluating new patient health profiles

---

## 💻 How to Run
1. Open this directory in VS Code or Jupyter Notebook:
   ```bash
   jupyter notebook Heart_Disease_Prediction.ipynb
   ```
2. Run all cells sequentially to view data visualizations, model training results, and predictive tests.
