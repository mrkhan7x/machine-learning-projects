# Weather Analytics & Visualization Dashboard

A data analytics dashboard that parses, standardizes, and visualizes atmospheric measurements across major global cities.

---

## 📌 Project Overview
* **Notebook:** [weather_dashboard.ipynb](weather_dashboard.ipynb)
* **Technologies:** Python, Pandas, Matplotlib, Seaborn
* **Author:** Muhammad Roman Khan

---

## 🚀 Workflow & Key Steps
1. Multi-city weather metric collection (Temperature, Humidity, Pressure, Wind Speed)
2. Statistical summaries and metric conversions
3. Bar chart visualizations across global metropolitan hubs
4. Temperature vs. Humidity regression analysis
5. Correlation heatmap of atmospheric indicators
6. Interactive city weather card lookup function

---

## 💻 How to Run
1. Open this directory in VS Code or Jupyter Notebook:
   ```bash
   jupyter notebook weather_dashboard.ipynb
   ```
2. Run all cells sequentially to view data visualizations, model training results, and predictive tests.
