# Supervised Model Comparison & Benchmark

A rigorous side-by-side benchmark comparing four core classification algorithms (Logistic Regression, Decision Tree, Random Forest, and SVM) on the same standardized dataset.

---

## 📌 Project Overview
* **Notebook:** [model_benchmark_comparison.ipynb](model_benchmark_comparison.ipynb)
* **Technologies:** Python, Scikit-Learn, Logistic Regression, Decision Tree, Random Forest, SVC, Seaborn
* **Author:** Muhammad Roman Khan

---

## 🚀 Workflow & Key Steps
1. Dataset preparation and feature standardization
2. Identical train/test split across all candidate models
3. Training Logistic Regression, Decision Tree, Random Forest, and SVM
4. Comparing Train vs Test Accuracy and F1-Scores
5. Comparative visualization bar plot

---

## 💻 How to Run
1. Open this directory in VS Code or Jupyter Notebook:
   ```bash
   jupyter notebook model_benchmark_comparison.ipynb
   ```
2. Run all cells sequentially to view data visualizations, model training results, and predictive tests.
