# Credit Card Fraud Detection (Imbalanced Data)

An anomaly detection and classification pipeline that addresses extreme class imbalance using Random Under-Sampling to reliably detect credit card fraud.

---

## 📌 Project Overview
* **Notebook:** [credit_card_fraud_detection.ipynb](credit_card_fraud_detection.ipynb)
* **Technologies:** Python, Pandas, Scikit-Learn, Random Under-Sampling, Logistic Regression, Seaborn
* **Author:** Muhammad Roman Khan

---

## 🚀 Workflow & Key Steps
1. Transaction data loading and class imbalance analysis
2. Comparing statistical properties of normal vs fraudulent transactions
3. Random under-sampling to create a uniformly balanced dataset
4. Feature separation and stratified train-test splitting
5. Logistic Regression classifier training
6. Model evaluation on training and testing sets
7. Predictive system classifying transaction risk

---

## 💻 How to Run
1. Open this directory in VS Code or Jupyter Notebook:
   ```bash
   jupyter notebook credit_card_fraud_detection.ipynb
   ```
2. Run all cells sequentially to view data visualizations, model training results, and predictive tests.
