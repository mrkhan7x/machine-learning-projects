# Diabetes Prediction using Logistic Regression

A healthcare predictive modeling project that forecasts whether a patient has diabetes based on medical diagnostic indicators.

---

## 📌 Project Overview
* **Notebook:** [diabetes_prediction.ipynb](diabetes_prediction.ipynb)
* **Technologies:** Python, Scikit-Learn, Logistic Regression, Pandas, Seaborn
* **Author:** Muhammad Roman Khan

---

## 🚀 Workflow & Key Steps
1. Medical dataset inspection and statistical profiling
2. Target class balance analysis (Diabetic vs Non-Diabetic)
3. Diagnostic feature correlation heatmap
4. Stratified train-test split (80/20)
5. Logistic Regression model fitting
6. Performance evaluation (Accuracy, Confusion Matrix)
7. Interactive predictive system with patient diagnostic inputs

---

## 💻 How to Run
1. Open this directory in VS Code or Jupyter Notebook:
   ```bash
   jupyter notebook diabetes_prediction.ipynb
   ```
2. Run all cells sequentially to view data visualizations, model training results, and predictive tests.
