# Diabetes Prediction using Support Vector Machine (SVM)

A medical classification pipeline using Support Vector Machines with linear kernels and StandardScaler feature normalization on the Pima Indians dataset.

---

## 📌 Project Overview
* **Notebook:** [diabetes_svm_prediction.ipynb](diabetes_svm_prediction.ipynb)
* **Technologies:** Python, Scikit-Learn, Support Vector Machine (SVC), StandardScaler, Seaborn
* **Author:** Muhammad Roman Khan

---

## 🚀 Workflow & Key Steps
1. Data exploration and missing value inspection
2. Feature standardization using StandardScaler
3. Stratified train-test split
4. Support Vector Classifier (`kernel='linear'`) training
5. Model evaluation on training and test sets
6. Real-time predictive system for patient records

---

## 💻 How to Run
1. Open this directory in VS Code or Jupyter Notebook:
   ```bash
   jupyter notebook diabetes_svm_prediction.ipynb
   ```
2. Run all cells sequentially to view data visualizations, model training results, and predictive tests.
