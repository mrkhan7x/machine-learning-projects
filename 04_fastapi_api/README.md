# FastAPI Task Management RESTful API

A production-grade REST API backend built with FastAPI and Pydantic schemas, interactively tested with HTTP test clients inside Jupyter.

---

## 📌 Project Overview
* **Notebook:** [fastapi_task_api.ipynb](fastapi_task_api.ipynb)
* **Technologies:** Python, FastAPI, Pydantic, TestClient, REST Architecture
* **Author:** Muhammad Roman Khan

---

## 🚀 Workflow & Key Steps
1. Defining strict request and response schemas using Pydantic
2. Implementing RESTful CRUD endpoints (`GET`, `POST`, `PUT`, `DELETE`)
3. Real-time in-notebook API testing using TestClient
4. Status verification and JSON response validation

---

## 💻 How to Run
1. Open this directory in VS Code or Jupyter Notebook:
   ```bash
   jupyter notebook fastapi_task_api.ipynb
   ```
2. Run all cells sequentially to view data visualizations, model training results, and predictive tests.
