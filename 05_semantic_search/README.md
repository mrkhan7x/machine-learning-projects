# Semantic Search & Information Retrieval Engine

An information retrieval engine that converts text documents into vector representations and ranks them against natural language user queries using Cosine Similarity.

---

## 📌 Project Overview
* **Notebook:** [semantic_search_engine.ipynb](semantic_search_engine.ipynb)
* **Technologies:** Python, Scikit-Learn, TF-IDF Vectorizer, Cosine Similarity, Seaborn
* **Author:** Muhammad Roman Khan

---

## 🚀 Workflow & Key Steps
1. Technical corpus collection and indexing
2. Document feature extraction using TF-IDF
3. Document-to-document cosine similarity matrix heatmap
4. Query vectorization and similarity score ranking
5. Ranked top-K search results display

---

## 💻 How to Run
1. Open this directory in VS Code or Jupyter Notebook:
   ```bash
   jupyter notebook semantic_search_engine.ipynb
   ```
2. Run all cells sequentially to view data visualizations, model training results, and predictive tests.
