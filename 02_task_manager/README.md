# CLI Task Manager Application

An Object-Oriented command-line task manager application featuring task creation, completion toggling, priority categorization, and persistent JSON storage.

---

## 📌 Project Overview
* **Notebook:** [task_manager.ipynb](task_manager.ipynb)
* **Technologies:** Python, OOP (Classes & Objects), JSON Persistence, Pandas
* **Author:** Muhammad Roman Khan

---

## 🚀 Workflow & Key Steps
1. Task entity modeling with timestamps and categories
2. TaskManager controller for CRUD operations
3. Interactive status table visualization
4. Task completion and deletion flows
5. Robust JSON read/write persistence

---

## 💻 How to Run
1. Open this directory in VS Code or Jupyter Notebook:
   ```bash
   jupyter notebook task_manager.ipynb
   ```
2. Run all cells sequentially to view data visualizations, model training results, and predictive tests.
