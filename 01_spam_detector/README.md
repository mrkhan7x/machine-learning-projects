# SMS Spam Detection

An end-to-end NLP classification model that categorizes SMS messages as Legitimate (Ham) or Spam using TF-IDF vectorization and Logistic Regression.

---

## 📌 Project Overview
* **Notebook:** [sms_spam_prediction.ipynb](sms_spam_prediction.ipynb)
* **Technologies:** Python, Pandas, Scikit-Learn, TF-IDF Vectorizer, Logistic Regression, Seaborn
* **Author:** Muhammad Roman Khan

---

## 🚀 Workflow & Key Steps
1. Data collection & preprocessing
2. Label encoding (Ham: 1, Spam: 0)
3. Exploratory Data Analysis & Seaborn distribution visualization
4. TF-IDF feature extraction
5. Train-test split (80/20)
6. Logistic Regression training
7. Model evaluation (Accuracy score)
8. Interactive predictive system for custom messages

---

## 💻 How to Run
1. Open this directory in VS Code or Jupyter Notebook:
   ```bash
   jupyter notebook sms_spam_prediction.ipynb
   ```
2. Run all cells sequentially to view data visualizations, model training results, and predictive tests.
